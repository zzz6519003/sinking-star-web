# 沉星之序 · 星落之境

一个可离线运行的非官方网页致敬原型，使用原生 JavaScript 和 Canvas 2D 绘制等距遗迹。复现战士推动、盗贼牵引、巫师换位的核心解谜规则，包含 8 个章节、28 道原创关卡。不是原作的完整移植，不包含原作素材、剧情或完整世界。

## 本地运行

需要 Node.js 18 或更高版本。项目没有第三方依赖，无需 `npm install`。

```sh
npm run dev
```

打开 http://localhost:4173 。macOS 也可以双击本目录的 `启动游戏.command`，启动后按终端提示打开游戏。关闭服务时按 `Ctrl+C`。

自定义端口：`PORT=4174 npm run dev`。服务仅监听本机 `127.0.0.1`。

## 玩法

将所有星晶放到金色符印上，星门就会开启；让任一同行者抵达星门即可过关。

- `W / ↑`：棋盘北方（屏幕右上）；`D / →`：棋盘东方（屏幕右下）。
- `S / ↓`：棋盘南方（屏幕左下）；`A / ←`：棋盘西方（屏幕左上）。
- 战士会推动前方连续的一列星晶。
- 盗贼无法推动，移动时自动拉动正后方的一枚星晶。
- 巫师沿移动方向，与视线中的第一个星晶或同伴交换位置；墙会挡住视线。没有目标时正常走一步。
- `1 / 2 / 3` 或 `Tab` 切换角色；点击角色卡或棋盘中的同伴也可切换。
- `Z` 撤销；`R` 重置当前关卡；`H` 显示或收起提示。
- 可点击空地自动行走；巫师建议使用键盘精确控制。手机提供四向触控按钮。
- 首次移动或点击后，自动启用轻柔的脚步与互动音效；右上角音符可静音，指南中可调音量并单独开启星庭环境音。
- 旅程地图可自由选择任一关，不强制解锁顺序。

关卡进度、最佳步数、当前局面、选中角色和最近 300 步历史自动保存在浏览器 `localStorage`。不同浏览器、不同端口的存档彼此独立。禁用浏览器存储时仍可游玩，但不能持久保存。

## 轻柔音效

- 三种职业有略微不同的石地脚步，左右脚交替，音色与力度轻微变化。
- 星晶推拉使用低沉摩擦声，换位使用气流与轻铃，归位和通关使用短和弦，撤销带轻柔的下降音。
- 默认音量 55%，首次操作后启用。音量与静音状态独立保存，不影响关卡存档。
- 游戏指南里的声音设置可调音量、选择稀疏的星庭环境音；切到后台会暂停声音。
- 声音使用渐入渐出、低通与轻混响，限制快速重复脚步并对整体动态作压缩，避免高频尖响和叠加削波。
- 真实音频检测页：`/test/audio-preview.html`。可生成 6.2 秒试听、检查输出电平并下载 WAV；自动测试不要求音频设备。

## 新增职业协作试炼（13–20 关）

在旅程地图中进入第五章「共鸣试炼」或第六章「同心星阵」。原有 12 关和存档编号保持兼容。

| 关卡 | 必需职业 | 协作方向 |
| --- | --- | --- |
| 13 推拉之约 | 战士 + 盗贼 | 牵出墙边星晶，再推动归位 |
| 14 隔岸相送 | 战士 + 巫师 | 狭窄支路中的推动与换位接力 |
| 15 回声渡口 | 盗贼 + 巫师 | 换出死角，牵引转向 |
| 16 三重共鸣 | 战士 + 盗贼 + 巫师 | 解困、转运与末端推送 |
| 17 逆流交接 | 战士 + 盗贼 | 腾出站位，逆向交接星晶 |
| 18 星桥易位 | 战士 + 巫师 | 交换同伴站位，送入窄路 |
| 19 牵光成环 | 盗贼 + 巫师 | 绕行牵引与跨通道换位 |
| 20 同心星阵 | 战士 + 盗贼 + 巫师 | 三种能力接力穿过窄井与支路 |

这些关卡依靠地形和职业规则形成协作需求，没有额外的“必须使用技能”通关计数。自动测试会逐一禁用队伍中一种职业的特殊能力（该角色仍可行走、占位、被巫师换位），穷举所有可达局面，确认无解；同时逐步回放正常队伍的完整通关路线。搜索触及上限会标记为未知，不作为无解证明。

## 验证

```sh
npm test
```

79 项测试覆盖 28 关完整通关路线，以及推动整列、牵引、巫师视线、与同伴换位、阻挡、通关条件和中途求解。浏览器验证覆盖归位开门、通关结算、撤销、刷新恢复、角色切换、动态提示、地图与手机触控。新增 13–20 关也已在浏览器中逐关回放完整通关路线，并验证第 20 关的刷新恢复与撤销。运行 `npm test` 不修改浏览器存档。

## 项目文件

- `index.html`、`src/style.css`：游戏界面与响应式布局。
- `src/engine.js`：不依赖 DOM 的纯规则引擎、通关判断、有限搜索求解器。
- `src/levels.js`：28 道原创关卡和角色资料。
- `src/render.js`：程序绘制的石庭、树木、遗迹、星晶和角色动画。
- `src/app.js`：键盘、点击、撤销、地图、存档和结算交互。
- `src/hint-worker.js`：在 Web Worker 中计算当前局面的下一步提示；达到搜索上限时返回静态提示。
- `src/audio.js`：Web Audio 合成脚步、推拉、换位、归位、撤销与通关音效，以及可选环境音；无外部音频资源。
- `test/solutions.json`：全部关卡的一条可行路线（包含解谜答案）。

游戏场景美术由程序绘制，字体使用系统字体，无需外部 CDN、账号或 API Key。场景为 2D 等距投影，音效与环境音均为合成音色。

右上角源码入口使用 [GitHub Corners](https://github.com/tholman/github-corners) 的 Octocat SVG，作者 Tim Holman，MIT 授权；完整声明保存在 `src/github-corners.LICENSE.txt`，随静态页面一起发布。

## 部署

- 在线游玩（Expo）：[sinking-star-zzz6519003.expo.app](https://sinking-star-zzz6519003.expo.app/)
- 备用入口（GitHub Pages）：[zzz6519003.github.io/sinking-star-web](https://zzz6519003.github.io/sinking-star-web/)
- 源码仓库：[zzz6519003/sinking-star-web](https://github.com/zzz6519003/sinking-star-web)

`npm run build` 只把游戏页面与 `src/` 打包到 `dist/`，不发布测试、截图、服务器源码或本地配置。页面资源与提示 Worker 均支持仓库子路径。

- GitHub Pages：推送 `main` 后，GitHub Actions 自动测试、构建并部署 `dist/`。
- Expo Hosting：本机登录 Expo 后运行 `npm run deploy:expo`，会重新构建并发布到正式环境。项目关联保存在 `app.json`，不含凭据。
- 本地运行仍使用 `npm run dev`，无需安装项目依赖。

不同域名使用独立的浏览器本地存档。GitHub Pages 与 Expo 的访问情况需要按具体地区和网络测试，不能保证所有国内线路都可达。
